# 随包记录 — 说明 — v0.1.0

这四份是 v0.1.0 的**原始验收记录**，从这里转交的目的是让产品侧不必进仓库也能核对交接里的每一条结论。

| 文件                             | 回答什么                                                                 | 对应交接的哪一节 |
| -------------------------------- | ------------------------------------------------------------------------ | ---------------- |
| `implementation-gates.md`        | 15 个阶段怎么分成 4 个 Gate、每个 Gate 当前是什么状态                     | 第 0、3.1 节     |
| `final-acceptance-v0.1.0.md`     | 最终验收记录：两门真实课程的人工基准、通过的关键路径、已知风险、产品反馈原文、E1–E5 工程发现 | 第 3、4、5 节    |
| `gate-d-consolidated-acceptance.md` | Gate D 那次真实测试的逐步结果表（PASS / FAIL / NOT TESTED），以及三个修复的机制说明 | 第 3.3–3.5 节    |
| `design-system.md`               | popup 的视觉契约：颜色、字体、组件，以及**已否决的视觉方向清单和否决理由** | 第 5 节反馈 5、第 6.3 节 |

两点必须说明：

1. **这四份是 2026-09-17 从仓库 `docs/` 复制的快照。仓库里的版本才是事实源**，本目录只是方便转交。两边不一致时以仓库为准。
2. **这四份是英文的**，因为仓库里的 `docs/` 一律英文。产品侧长期保留的中文结论在交付包的 `PRODUCT_HANDOFF_v0.1.0.md` 里。

没有放进来的：`Syllab_Technical_Design_Handoff_v0.1.0/`（PRD、决策日志、交互与 IA 规范、技术设计、实现计划）——那些是产品侧自己的产物，不需要回给产品侧；`15_GATE_D_TESTING_HANDOFF_v0.1.0.md` 是给执行测试的 agent 的操作手册，不是验收材料。
