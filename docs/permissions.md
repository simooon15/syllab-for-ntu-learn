# Manifest permission rationale

| Permission                                                            | Scope                                  | Purpose                                                                                                                                                                                           |
| --------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `storage`                                                             | Extension                              | Persist local course state, workflow checkpoints, settings, and the user's BYOK DeepSeek API key in Chrome extension storage.                                                                     |
| `activeTab`                                                           | User-selected active tab               | Read the current tab context only when the user opens or invokes Syllab.                                                                                                                          |
| `scripting`                                                           | Extension                              | Inject the controlled page bridge when a Blackboard page-context read is required.                                                                                                                |
| `webRequest`                                                          | Read-only request events               | Observe the redirect destination of a discovered NTU WebDAV attachment request. It does not grant a host; listeners are scoped to the exact discovered path and raw URLs are not logged.          |
| `offscreen`                                                           | Hidden extension page                  | Host a short-lived, packaged parser document that starts one isolated Worker per file. It has no visible UI and receives no additional site permission.                                           |
| `sidePanel`                                                           | Extension UI                           | Open Syllab in Chrome's Side Panel beside NTU Learn tabs so students can inspect courses and review changes without losing page context.                                                          |
| `tabs`                                                                | Extension                              | Identify NTU Learn tabs for course context routing and open the Full-page Workspace (`app.html`) from the Side Panel.                                                                             |
| `alarms`                                                              | Extension                              | Schedule low-frequency background Opportunity Checking and resume parked workflows after transient backoff elapses.                                                                               |
| `downloads`                                                           | Extension                              | Export local JSON backups and confirmed `.ics` calendar files to the user's machine.                                                                                                              |
| `https://ntulearn.ntu.edu.sg/*`                                       | Granted host                           | Load the read-only content script and perform authenticated same-origin reads on the target NTU Learn site.                                                                                       |
| `https://api.deepseek.com/*`                                          | Granted host                           | Send BYOK extraction and verification requests directly from the extension service worker to DeepSeek once the user explicitly authorizes privacy/API usage and supplies a key.                   |
| `https://*.blackboard.com/*`, `https://*.prod.files.blackboard.com/*` | Optional host (not granted at install) | Allow runtime permission requests for exact redirected Blackboard/Xythos attachment origins discovered during an active Scan, triggered only by an explicit Side Panel or Full-page user gesture. |

No broad Blackboard host permission is granted at installation. Optional permissions are requested
only for an exact redirect origin matching `optional_host_permissions` discovered during an active
Scan and only from a Side Panel or Full-page user gesture.
